# System dictation

In the current source build, open **Settings → System Dictation** to run setup. Allow Microphone and Accessibility in macOS, then try the shortcut in the practice field. By default, hold **Right Option** while you speak and release it to insert text. Double-tap **Right Option** to record hands-free, then press it again to finish. **Esc** cancels a take and **Option–Shift–V** pastes the last dictation.

Dictation works while the Jard window is closed and the app is running. It uses Rumble2 Flash on the Mac. Settings include the shortcut, input device, language, vocabulary, output, and text-only history. The default history retention is seven days.
